# Примеры кода

## Inline code

Оформляйте как inline code команды, имена файлов, параметры, значения и идентификаторы: `mkdocs.yml`, `--strict`, `DEBUG=true`.

## Блоки кода

По возможности указывайте язык fenced code block. Перед примером объясните его назначение, а после — результат, если он не очевиден.

```python
def greet(name: str) -> str:
    return f"Привет, {name}!"
```

## Команды

Одну короткую команду можно включить в предложение. Последовательность команд оформляйте отдельным блоком:

```powershell
python -m pip install -r requirements.txt
mkdocs serve
```

## Содержание примера

- Оставляйте только код, который относится к объясняемой задаче.
- Делайте пример самодостаточным в пределах раздела.
- Разбивайте длинный листинг или заменяйте второстепенную часть пояснением.
- Никогда не показывайте реальные пароли, токены и другие секреты.
