# Терминология

Одинаковые сущности называйте одинаково на всех страницах. При первом упоминании незнакомого сокращения дайте расшифровку, а технические обозначения сохраняйте в принятом написании.

| Сущность | Использовать | Не использовать без необходимости |
| --- | --- | --- |
| Account | учётная запись | аккаунт, профиль |
| Sign in | войти | авторизоваться, залогиниться |
| Sign out | выйти | разлогиниться |
| Web application | веб-приложение | веб-сервис, сайт |
| Person using the product | пользователь | клиент, юзер |
| Software author | разработчик | программист |
| Application Programming Interface | API | программный интерфейс |
| Web address | URL | ссылка, адрес страницы |
| Data format | JSON | json, Json |

Например, для основного действия используйте «войти». Не чередуйте на одной странице варианты «авторизоваться», «залогиниться» и «войти», если они обозначают одно действие.
