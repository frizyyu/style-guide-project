# Структура документа

Один документ должен раскрывать одну основную тему. Название отражает содержание, а первый абзац кратко объясняет назначение страницы.

## Структура инструкции

1. Название.
2. Краткое описание результата.
3. Предварительные условия, если они нужны.
4. Последовательность действий.
5. Проверка результата.

## Заголовки

Используйте информативные заголовки и соблюдайте их иерархию. Не создавайте глубокую вложенность без необходимости и не пропускайте уровни.

## Абзацы

Один абзац раскрывает одну основную мысль. Если тема изменилась, начните новый абзац или раздел.

## Списки

Набор равнозначных элементов оформляйте маркированным списком. Для действий, которые нужно выполнить по порядку, используйте нумерованный список.

## Пошаговые инструкции

Один шаг должен описывать одно основное действие. Начинайте шаг с глагола и не объединяйте независимые действия союзом «и». После шагов объясните, как проверить результат.
