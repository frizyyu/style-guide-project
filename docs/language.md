# Стиль изложения

- Используйте спокойный нейтральный тон без неоправданной эмоциональности.
- Выбирайте понятные формулировки и по возможности активные конструкции.
- Обращайтесь к читателю на «вы» и последовательно используйте этот вариант.
- Избегайте канцеляризмов и цепочек отглагольных существительных.
- Делите длинные предложения, если в них смешано несколько мыслей.

Плохо: «Для осуществления запуска приложения необходимо выполнить команду».

Лучше: «Чтобы запустить приложение, выполните команду».

# Орфография и пунктуация

- Соблюдайте правила русского языка.
- Последовательно используйте букву «ё» там, где она требуется.
- В русском тексте используйте кавычки-«ёлочки».
- Технические идентификаторы, например `user_id`, оставляйте в исходном написании.
- Даты записывайте как `2 октября 2026 года`, время — в 24-часовом формате.
- Не используйте восклицательные знаки без необходимости.
- Завершайте полные предложения подходящим знаком препинания.
