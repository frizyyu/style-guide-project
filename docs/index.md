# Style Guide Project

Это руководство задаёт единые правила технической документации веб-приложения. Оно предназначено для разработчиков и технических писателей, которые создают материалы для пользователей и разработчиков.

## Основные принципы

- Пишите понятно и кратко.
- Сохраняйте единые термины и оформление.
- Учитывайте задачу и знания читателя.
- Поддерживайте сведения в актуальном состоянии.
